# 🏋️‍♂️ GIMNASIO AGROFIT

Sistema de gestión y control para la administración de rutinas de entrenamiento y usuarios del gimnasio.

## 🚀 Tecnologías
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript.
* **Backend:** Python (POO).
* **Base de Datos:** MySQL / phpMyAdmin.

## 📌 Descripción
Proyecto desarrollado para optimizar la organización y asignación de rutinas de entrenamiento, facilitando el control y seguimiento de los estudiantes.
